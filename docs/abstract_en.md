# Alpha221: Genetic Algorithm for Risk-Constrained Portfolio Optimization

We are building a course project that helps individual investors choose how to divide money among selected stocks. The program will use historical daily prices and a risk limit to suggest portfolio weights and estimate return and risk. We will start with companies from AI, game development, and semiconductor sectors.

The program uses a genetic algorithm with population initialization, selection, crossover, mutation, and fitness evaluation. It calculates returns and covariance from daily price changes, then compares the result with an equal-weight portfolio and a Markowitz optimizer. Our target is for every GA portfolio to meet the risk limit and for the median of five annual GA to Markowitz return ratios to reach at least 0.95.

The runnable Python application is in place. It can generate synthetic prices for a demo, prepare a wide CSV from per-ticker Kaggle files, and compare methods by calendar year. The annual report includes the median genetic algorithm to Markowitz return ratio and is saved to `results/comparison.csv`. We selected the CC0 [Huge Stock Market Dataset](https://www.kaggle.com/datasets/borismarjanovic/price-volume-data-for-all-us-stocks-etfs), but have not downloaded or evaluated it yet. The demo is not a project result. The program runs on CPU and is a course project, not investment advice.
