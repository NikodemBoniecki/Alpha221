# Alpha221: Genetic Algorithm for Risk-Constrained Portfolio Optimization

We are building a course project that helps individual investors choose how to divide money among selected stocks. The program will use historical daily prices and a risk limit to suggest portfolio weights and estimate return and risk. We will start with companies from AI, game development, and semiconductor sectors.

We will implement a genetic algorithm with population initialization, selection, crossover, mutation, and fitness evaluation. We will calculate returns and covariance from daily price changes. We will compare the algorithm with an equal-weight portfolio and a Markowitz optimizer using the same test periods. Our initial target is for every returned portfolio to meet the risk limit and for median return to reach at least 95% of the Markowitz result across five test cases.

We have not selected the tickers or date range, written the code, or run experiments yet. We plan to use Tiingo EOD only if a license allows us to store the data and evaluate the algorithm. Otherwise, we will choose a dataset with suitable terms. The program will run on CPU. This is a course project, not investment advice.
